   # Samarbete i ett gemensamt repository

   Ett gemensamt repository används av ett utvecklingsteam för att alla
   ska kunna arbeta i samma kodbas utan att skriva över varandras
   ändringar. Med hjälp av branches, commits, push och pull kan flera
   personer utveckla parallellt, granska varandras kod exemplevis genom pull requests och sedan slå ihop ändringarna in i huvudkoden.
